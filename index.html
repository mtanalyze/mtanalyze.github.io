New in 1.1: multi-document tabs

The fast way through a stack of SWIFT MT messages.

Open-source desktop tool for everyone working with SWIFT MT messages. Load any mix of MT files into one harmonized entries table, read the ISO 15022 meaning of every field, and compare messages side by side — built directly on the ISO 15022 message model, so any valid SWIFT MT message is handled without loss of information.

Download latest release View on GitHub

Single self-contained JAR · requires Java 17+ · no installation, no admin rights

One harmonized entries table

Import a whole directory of files, or a raw log file with embedded SWIFT messages — any mix of MT types lands in the same table. Nested repeating sequences — each with its own dates, quantities and parties — become one flat, sortable, filterable row per entry, no matter how deep the original SWIFT structure was; simpler MTs a single row. Entries stay linked through shared references across the transaction chain, so you can trace a transaction without cross-referencing in a text editor.

Detail view on every row

Click a row for Tags (with ISO 15022 descriptions), Components and Source. Select two or more rows and the Diff tab opens automatically with deviating cells highlighted.

Made for everyday work

Excel-style filters and a quick expression language (=EUR, ^DE, !=FREE). Right-click Copy on the table or detail view to paste straight into Excel.

Multi-document tabs

Someone needs a quick check mid-batch? Open it in a new tab and keep going. Each tab keeps its own Tags, Components, Source and Diff — nothing is lost, nothing needs reloading.

Supported message types

MT Analyze ships with type-aware handling for the SWIFT MT messages most relevant to securities post-trade, corporate actions and cash reporting. Files of other MT types still parse via Prowide Core — if the type can’t be detected, you’ll be prompted to pick one.
