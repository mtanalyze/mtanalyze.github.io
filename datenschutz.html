2. Hosting via GitHub Pages

This website is hosted as a static site on GitHub Pages, a service provided by GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. GitHub is a subsidiary of Microsoft.

When the site is accessed, technically necessary connection data is collected by GitHub and stored in server logs. This typically includes:

  • IP address of the requesting device
  • Date and time of the request
  • Requested URL
  • HTTP status code and amount of data transferred
  • User agent (browser, operating system)
  • Referrer (previously visited page)

The legal basis is Art. 6(1)(f) GDPR; the legitimate interest lies in the technically error-free provision of the website and the prevention of misuse. We have no influence over how GitHub handles this data; GitHub's own privacy policy additionally applies: GitHub General Privacy Statement .

Since GitHub Pages may transfer personal data to the USA, this transfer relies on the European Commission's Standard Contractual Clauses and, where applicable, the EU-US Data Privacy Framework.

This website does not use cookies, does not use any web analytics tools (no Google Analytics, Matomo, Plausible, or similar), and does not embed any external fonts, scripts, or trackers. All content is served exclusively by the hosting provider. No cross-device recognition or profiling takes place.

5. Atom Feed

This site provides an Atom feed for release announcements at https://github.com/mtanalyze/mtanalyze/releases.atom.
